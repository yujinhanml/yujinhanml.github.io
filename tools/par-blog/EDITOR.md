# PAR 本地网页编辑

先构建 Jekyll 网站，再启动编辑器：

```sh
python3 tools/par-blog/editor.py --site /private/tmp/par-blog-build/site --port 4318
```

打开 http://127.0.0.1:4318/blogs/prompt-aware-rubrics/zh/ 。

- 点击正文、标题、列表、表格单元格或图注，直接修改文字。
- 点击“保存草稿”或按 ⌘/Ctrl+S。保存会写回当前语言的文章 HTML；不会提交或上传。
- “预览”显示已保存的草稿，包含正常的公式渲染；编辑时公式保留 TeX 源码。
- 中英文可分别修改。只修改中文时，后续可请 Codex“同步英文并上传”。
- 退出或切换语言前先保存。未保存的改动会暂存于当前浏览器；刷新同一版本时会恢复。
- 保存前的源文件备份位于系统临时目录的 `par-blog-editor-backups/`。

编辑器只监听本机。页面改动以源文件哈希校验，防止多个窗口相互覆盖。
编辑模式只在本地服务器注入，不会出现在公开博客页面中。

后续发布时，应先查看两种语言的源文件 diff，按用户意图同步翻译，再构建检查并发布。
